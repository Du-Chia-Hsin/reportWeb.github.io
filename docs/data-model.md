## 與既有文件的落差（待討論，尚未定案）

1. **缺同步狀態欄位**：架構圖與 docx 的核心機制是 `sync_status` = `pending` / `updated`，Sheet 目前沒有這欄。
2. **`目前狀態` vs 「結案」**：docx 的雲端清理條件需要「處理狀態 = 已結案」。目前只看到「待確認」一種值，完整選項未知。
3. **`ID` 產生規則不明**：`e0f84a35` 像 8 碼 hex，其餘像隨機英數且長度不一（7~8 碼）。docx 建議用 UUID + 時間戳做 idempotency key。
4. **`提出者` / `責任單位` 混用**：兩欄都出現「禾宇」與「AE01」，值域似乎相同（廠商名 + 內部單位代號），但沒有欄位標明該筆屬於哪個項目 / 哪家廠商 —— GAS 要靠金鑰過濾資料時，缺少可對應 `Facilities.項目名稱` 的欄位。
5. **無時間戳**：只有日期（`M/d/yyyy`），沒有時分秒，難以判斷同步先後。
6. **`vendor-portal/src/App.vue` 現有欄位對不上**：程式碼寫的是 `machine_code` / `status_code` / `temperature`，與這張表完全無關，需重寫。
